# Indian Sign Language Recognition — ISL Prototype

A real-time **Indian Sign Language (ISL) recognition prototype** that uses computer vision and deep learning to recognize sign-language gestures from a webcam.

The system extracts human pose and hand landmarks using **MediaPipe Holistic**, processes temporal sequences of landmarks using a **Bidirectional LSTM (Bi-LSTM)** model, and performs real-time sign prediction through a webcam.

---

##  Overview

This prototype is designed as an end-to-end ISL recognition pipeline covering:

- Real-time webcam input
- Human pose landmark extraction
- Left and right hand landmark extraction
- Temporal sequence modelling using Bi-LSTM
- Top-3 prediction probabilities
- Real-time inference using TensorFlow Lite / LiteRT
- Custom data collection and model training
- Conversion toward a lightweight production inference model

The prototype currently contains two recognition pipelines:

1. **Custom prototype pipeline** — train and test a model using a small custom vocabulary.
2. **Production inference pipeline** — run an existing `.tflite` model for real-time recognition.

##  Feature Extraction

Each video frame is converted into **258 numerical features**:

| Component | Landmarks | Features |
|---|---:|---:|
| Pose | 33 | 132 |
| Left Hand | 21 | 63 |
| Right Hand | 21 | 63 |
| **Total** | **75** | **258** |

For pose landmarks, the system stores:

```text
x, y, z, visibility
```

For hand landmarks:

```text
x, y, z
```

The resulting feature vector is:

```text
132 + 63 + 63 = 258 features/frame
```

The model processes **30 consecutive frames**, resulting in an input sequence of:

```text
30 × 258
```

The training pipeline explicitly validates that each sequence has this shape before including it in training.

#  Files Explained

### `record_custom.py`

Used to collect custom training data through the webcam.

The current custom prototype contains six demonstration signs:

```text
Hello
Thank You
Yes
No
Help
Stop
```

The script records **30 sequences per sign**, with each sequence containing **30 frames** of 258-dimensional landmark features.

Press **SPACEBAR** to start recording the current sign.



The generated data is stored as:

```text
custom_data/
├── Hello/
├── Thank You/
├── Yes/
├── No/
├── Help/
└── Stop/
```

Each sequence is saved as a `.npy` file with shape:

```text
(30, 258)
```



---

### `train_custom.py`

Trains the custom ISL recognition model.

The script:

1. Loads the collected `.npy` sequences.
2. Creates class labels.
3. Splits the dataset into training and validation sets.
4. Builds a Bidirectional LSTM model.
5. Trains the model.
6. Saves the trained model as `custom_model.h5`.
7. Exports the corresponding labels to `custom_labels.json`.



### Model Architecture

```text
Input: 30 × 258
       │
       ▼
Masking
       │
       ▼
Bidirectional LSTM (64)
       │
       ▼
Dropout
       │
       ▼
Batch Normalization
       │
       ▼
Bidirectional LSTM (64)
       │
       ▼
Dropout
       │
       ▼
Batch Normalization
       │
       ▼
Dense (64, ReLU)
       │
       ▼
Dropout
       │
       ▼
Softmax Output
```



Training uses the Adam optimizer and categorical cross-entropy loss, with early stopping based on validation loss.

---

### `live_custom.py`

Runs the custom `.h5` model using a webcam.

The model expects:

```text
30 frames × 258 features
```

and uses a confidence threshold of `0.70` with two consecutive matching predictions before updating the detected sign.

The interface displays:

- Current detected sign
- Confidence
- Top-3 predictions
- Temporal buffer status
- MediaPipe pose and hand landmarks

---

### `isl_production_model.tflite`

A lightweight TensorFlow Lite model intended for production-style inference.

The production inference code loads this model through **LiteRT when available**, with a TensorFlow Lite fallback.

This makes the model suitable for experimentation with lightweight and edge-oriented inference.

---

### `labels.json`

Contains the class mapping used by the production model.

The mapping contains **262 classes**, including signs such as:

```text
Hello
How are you
Thank you
Good morning
Good afternoon
Good evening
Good night
Yes
No
Help
...
```

The label file contains classes covering people, objects, actions, descriptions, time-related terms and other vocabulary.

---

### `custom_labels.json`

Contains the class mapping for the custom six-sign prototype:

```text
Hello
Help
No
Stop
Thank You
Yes
```



---

### `demo_app.py`

Main real-time demonstration/inference script for the production TFLite model.

It:

- Opens the webcam.
- Detects pose and hand landmarks.
- Extracts 258 features per frame.
- Maintains a 30-frame temporal buffer.
- Runs TFLite/LiteRT inference.
- Displays the top-3 predictions.
- Uses consecutive predictions to stabilize the detected sign.



The interface also displays a temporal buffer indicator and the detected sign with its confidence score.

---

### `diagnose.py`

Utility script for checking the production TFLite model.

It prints:

- Expected input tensor shape
- Input data type
- Output tensor shape
- Number of classes in `labels.json`
- Sample class labels



Run this before inference if you want to verify that the model and label mapping are compatible.

#  Real-Time Prediction

The production inference pipeline uses a temporal buffer:

```text
Frame 1
Frame 2
Frame 3
...
Frame 30
       │
       ▼
    Model
       │
       ▼
Prediction probabilities
       │
       ├── Top 1
       ├── Top 2
       └── Top 3
```

A prediction is accepted after reaching the configured confidence threshold and obtaining consecutive matching predictions. This helps reduce unstable frame-by-frame predictions.

# Prototype Limitations

This repository represents a **prototype**, not a complete production-ready ISL translation system.

Recognition performance can depend on:

- Camera quality
- Lighting conditions
- Background
- Camera position
- Sign execution speed
- Distance from camera
- Visibility of hands and body
- Similarity between different signs

The custom training pipeline is primarily intended for experimentation and demonstration.
